# Unified envelope — experimental Stage 04U
All objects use exactly schema, type, op, payload, children. schema = uco.unified.v0.1. i32/value carries a checked signed integer and no children; i32/add carries null and two i32 expressions. A program is a tree of the same envelopes; its result is an i32/value envelope usable directly as a child in another program. State/checkpoint uses the same outer envelope with payload {object_hash, plan_hash, cursor} and children containing completed value envelopes. State is not an arithmetic operand. No implicit execution of data, arbitrary code, self-modification or untyped coercion. Checkpoints bind to the original object and passport-derived plan; resume validates by deterministic replay and therefore does not save compute. Grants are explicit simulation inputs, not authenticated credentials.
Limits: 32 depth, 4096 expression nodes, 1–64 simulated lanes, device max_items bounds primitive operation count. Execution sequential. Legacy vector and composition envelopes remain unchanged; migration adapters are deferred. This is representational unification, not proof of semantic identity between code and data.
