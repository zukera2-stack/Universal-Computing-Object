# Stage 03C — recursive composition experiment
Stacked on Stage 02G; original roadmap migration milestone remains deferred. Versioned composition envelope contains a recursive expression: literal(value: checked i32) or add(children: exactly two expressions). Both use the same recursive lowering function. Example ((2+3)+(4+5)) -> 14. Compiler emits one dependency-ordered primitive DAG; scheduling respects predecessor batches and passport lane capacity. Interpreter executes sequentially. No runtime recursion, loops, arbitrary functions, references between envelopes, general-purpose language, true parallelism, or hardware driver generation. Limits: depth 32, at most 4096 visited expressions and passport max_items; reject cycles, invalid grants and overflow. No reassociation (checked overflow is observable). No common subexpression elimination. New schema is experimental and separate from Stage 01 vector envelope. Tests: python -m unittest discover -s tests -v. CI pending at submission.
