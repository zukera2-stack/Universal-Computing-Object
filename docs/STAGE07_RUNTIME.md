# Stage 07R — integrated simulated runtime
The runtime coordinates the Stage 04U expression compiler, Stage 05M authenticated migration and Stage 06A adaptive Memory without replacing their implementations. Inputs: unified expression, explicit grants, trusted simulated device registry with cost estimates, optional availability trace, shared secret. At every quantum, read the object from content-addressed simulated memory, reject incompatible devices, minimize next-slice cost plus a fixed switching penalty of 2, advance the same authenticated logical prefix, serialize intermediate state, and store/read the final value. Equal scores break ties lexically. The demo uses three additions, one-operation quantum, home cost 3 / one lane and server cost 1 / eight lanes; home chosen twice (second step tie), then server after home becomes unavailable. Expected result 14, three actual additions, one migration. Instrumented tests verify no replay, logical identity, choice and fallback, memory integrity, rejection and determinism. Run python -m uco_demo.runtime and python -m unittest discover -s tests -v.
Limitations: availability is supplied by a deterministic simulation, not discovery or failure detection; no real network, parallel speedup or persistent checkpoint storage. Checkpoint transport is JSON in RAM, not integrated into adaptive Memory because its validator currently accepts expressions only. Failure aborts the current call; there is no durable recovery or transactional rollback. Device cost is illustrative, not measured. Plan compilation is repeated per candidate and per quantum, and the destination must fit the whole plan. Memory size units estimated from serialized bytes; existing identical objects reuse placement and initial deadline. Shared HMAC trust, no encryption or anti-replay; no external side effects. Sequential in-process coordination, not a production OS. Original roadmap peripheral and independent implementation milestones remain open. CI pending at submission.
