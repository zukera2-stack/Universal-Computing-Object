# Stage 06A — adaptive memory simulation
Three finite exclusive tiers: hot 8 units / latency 1 / rent 3; warm 16 / latency 5 / rent 1; cold 64 / latency 20 / rent 0. Movement costs 2 units per size unit per tier distance. All costs are illustrative dimensionless simulation weights, not real prices or latency measurements. Objects are immutable serialized unified expressions; size and deadline are caller-supplied model parameters, not actual byte counts. Both policies see identical traces, inputs, capacity and accounting. LRU eagerly promotes accessed items, evicting least-recent occupants; adaptive policy compares decayed access frequency and deadline penalties against rent and movement costs. Both use atomic capacity-checked swaps; no deletion or automatic idle-only demotion. Deadline is a soft preference, not a guarantee. The simulator charges access before promotion, storage after each access, and every promoted/evicted byte-unit; no wall-clock timing. Run python -m uco_demo.memory for numerical results and python -m unittest discover -s tests -v for conformance. Four deterministic traces: stable hot set, sequential scan, phase change, mixed. No claim of universal superiority; inspect total costs and deadline misses separately. Not an actual RAM/SSD/cloud manager, not integrated into migration or execution runtime.
