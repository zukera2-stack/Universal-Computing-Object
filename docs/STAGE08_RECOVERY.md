# Stage 08F — real local process failover
Acceptance: spawn independent OS workers with different simulated passports, commit each quantum to a disk journal, kill primary after two confirmed additions, detect nonzero exit, start backup, recover and finish with exactly three instrumented committed additions and result 14. Use multiprocessing spawn on Windows and Linux. Workers receive explicit grants and shared secret from trusted supervisor. Atomic same-directory replacement, file fsync and POSIX directory fsync; Windows directory durability not asserted. Journal wraps authenticated checkpoint or result in HMAC-SHA256 and binds it to job and logical identity. Only one worker writes at a time; exclusive fresh journal creation. Timeout/EOF triggers bounded replacement; arithmetic errors fail closed. Run python -m unittest discover -s tests -v.
Limitations: fault injection happens after acknowledged disk commit, not mid-instruction; an interrupted uncommitted quantum may be repeated. There is no distributed consensus, exactly-once external side effects, anti-rollback, encryption, machine/network failure recovery or supervisor restart API. Local trust includes directory, worker code, key and supervisor; process isolation is not a sandbox. This is a separate recovery supervisor reusing Stage 05 migration/compiler; it does not yet integrate Stage 07 cost scheduler or Stage 06 adaptive memory. Tests measure actual primitive calls for acknowledged quanta, not uncommitted attempts. Filesystem power-loss durability not proven. CI pending at submission.
